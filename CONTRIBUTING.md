# 🤝 Contributing to Shopify Store Lead Extractor

We welcome contributions from developers and data engineers!

## How to Contribute
1. Fork the repository on GitHub.
2. Create a new feature branch (`git checkout -b feature/amazing-feature`).
3. Commit your changes (`git commit -m 'feat: add new app fingerprinting rule'`).
4. Push to the branch (`git push origin feature/amazing-feature`).
5. Open a Pull Request.

## Code Standards
- Ensure Python code adheres to PEP 8 standards.
- Run tests in `tests/` before opening a Pull Request.
