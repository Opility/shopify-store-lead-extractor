# 🚀 Deployment Guide

## Deploying to Apify Store

1. **Link GitHub Repository**:
   Connect `https://github.com/Opility/shopify-store-lead-extractor` on Apify Console.

2. **Automatic Build Configuration**:
   Enable Automatic Builds under Build Settings.

3. **Deploy via Apify CLI**:
   ```bash
   apify login
   apify push
   ```
