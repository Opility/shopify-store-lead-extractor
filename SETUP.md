# 🛠️ Setup & Installation

## Prerequisites
- Python 3.11+
- Apify CLI (`npm install -g apify-cli`)

## Local Quickstart
1. **Clone repository**:
   ```bash
   git clone https://github.com/Opility/shopify-store-lead-extractor.git
   cd shopify-store-lead-extractor
   ```

2. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

3. **Run locally**:
   ```bash
   apify run
   ```
